# Student Obesity Analysis Using Height and Weight Data

## Objective
To analyze obesity levels among 64 students using height and weight measurements and visualize the data using Histogram, Violin Plot, and Heatmap.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Obesity Dataset containing student height, weight, age, and obesity category information.

## Visualizations
1. Histogram
2. Violin Plot
3. Heatmap

## Conclusion
The project analyzes obesity categories and explores relationships between age, height, and weight through data visualization techniques.
